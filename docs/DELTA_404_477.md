# Protocol delta: 404 (1.13.2) → 477 (1.14)

Sources: PrismarineJS `minecraft-data` `1.13.2` / `1.14` `protocol.json`,
Mojang jars (`minecraft-*-1.14.jar`, SHA-256 verified), wiki.vg Protocol History,
and Conduit's existing codecs (`BlockPositionCodec`, `ItemCodec`, chunk codecs).

## Summary

| Axis | Change |
| --- | --- |
| Protocol numbers | 404 → 477 |
| Packet id tables | **many remaps** (~85 kinds); **not** arithmetic offsets |
| Configuration state | none (both predate config phase) |
| Framing / VarInt / compression | unchanged |
| Handshake / status / login | unchanged field layouts |
| **Slot wire form** | **unchanged** (both use present+VarInt from 404) |
| **Join Game / Respawn** | difficulty removed; viewDistance added (Join Game) |
| **Open Window** | string type → menu registry VarInt; windowId → VarInt; title stays JSON |
| **Chunk Data** | heightmaps NBT inserted; section light removed |
| **Update Light / View Position / Distance** | **new** clientbound packets |
| **Block Position packing** | Y-middle → Y-low (same change as 393↔765 boundary) |
| **Block Place** | hand moved first; `insideBlock` bool added (no prediction sequence yet) |
| **Spawn Object type** | i8 → VarInt |
| **Use Bed** | **removed** |

## High-priority field deltas

### Join Game (S→C, id 0x25 both)

| Era | Layout |
| --- | --- |
| 404 | entityId:i32 gameMode:u8 dimension:i32 **difficulty:u8** maxPlayers:u8 levelType:String reducedDebugInfo:bool |
| 477 | entityId:i32 gameMode:u8 dimension:i32 maxPlayers:u8 levelType:String **viewDistance:VarInt** reducedDebugInfo:bool |

Semantic: reuse `JoinGamePacket`. Absorb difficulty 404→477; synthesise viewDistance (default 10) 404→477; synthesise difficulty (default 2) 477→404.

**Not** the 1.16+/765 registry Join Game. Treating 477 as “modern 765” is incorrect.

### Respawn (S→C)

| Era | Layout |
| --- | --- |
| 404 | dimension:i32 **difficulty:u8** gamemode:u8 levelType:String |
| 477 | dimension:i32 gamemode:u8 levelType:String |

### Open Window (S→C)

| Era | Layout |
| --- | --- |
| 404 | windowId:u8 type:String title:JSON slots:u8 [entityId] |
| 477 | windowId:VarInt menuType:VarInt title:JSON |

Title is still JSON Chat (NBT text components arrive much later). Reuse existing menu id ↔ string maps in `ContainerCodec`.

### Chunk Data (S→C)

| Era | Layout |
| --- | --- |
| 404 | x z groundUp bitMap **chunkData** blockEntities |
| 477 | x z groundUp bitMap **heightmaps:NBT** chunkData blockEntities |

Section bodies: 404 includes blockLight+skyLight per section; 477 does not — light moves to Update Light.

### Update Light / View Position / View Distance (S→C)

New on 477. Toward 404: **absorb** (drop). Toward 477: **synthesise** light from section light when rematerialising chunks; synthesise view distance from Join Game; view position from player chunk coords when known.

### Player Block Placement (C→S)

| Era | Layout |
| --- | --- |
| 404 | location face hand cursor×3 |
| 477 | **hand** location face cursor×3 **insideBlock** |

Position long must be rematerialised via `BlockPositionCodec`. No sequence field (that is 1.19+).

### Block Dig / Block Change / Spawn Position / etc.

Bodies otherwise similar, but any packed Position must be rematerialised across the packing change.

### Spawn Object (S→C)

`type` becomes VarInt (was i8). Living/player spawn layouts otherwise same at the packet layer; entity type numeric ids may diverge for newer mobs.

## What can be forwarded opaquely (same kind, remapped id only)

Keep-alive, chat, plugin message, movement, teleport confirm, unload chunk,
game event, abilities (clientbound), health, experience, many entity move/
look/velocity/teleport packets (ids remapped), container content/slot/click
(Slot form identical), confirm transaction, creative slot, held item, swing.

## Architectural choice

`Protocol404To477Translator` — small delta adapter on the existing semantic
pipeline (same pattern as `Protocol393To404Translator`), not a new translation
architecture and not a pair explosion toward 393/765.

Era boundaries that 404↔477 forces us to stop conflating with `> 404`:

| Concern | Boundary |
| --- | --- |
| Slot present+VarInt | ≥ 404 |
| Position Y-low packing | ≥ 477 |
| Open Window menu id | ≥ 477 |
| Chunk heightmaps / no section light | ≥ 477 |
| Equipment multi-slot array | ≥ 735 (1.16) |
| Container stateId | ≥ 755 (1.17) |
| Join Game registry / hardcore / world list | ≥ 735 |
| Block place sequence | ≥ 759 (1.19) |
| Open Window NBT title | ≥ 765 |

## Block / item registry note

Early block states (air, stone, dirt, grass, planks, cobble, oak_log) share
ids between 1.13.2 and 1.14; later ids (e.g. chest) shift. First implementation
passes state/item ids numerically for 404↔477 and documents mismatches as a
known PARTIAL limitation until dedicated 477 maps exist.
