# Chunk format: protocol 393 (1.13) ↔ 765 (1.20.4)

Public protocol data only (PrismarineJS `minecraft-data`, wiki.vg Chunk Format).
No third-party proxy implementation source.

## Packet structure

| Field | 393 Chunk Data | 765 Chunk Data |
|---|---|---|
| Chunk X/Z | int, int | int, int |
| Full chunk | boolean `groundUpContinuous` | always full in modern Play send |
| Section mask | VarInt primary bitmask (16 bits) | implicit: 24 ordered sections in buffer |
| Heightmaps | none in chunk packet | network NBT compound |
| Section buffer | VarInt size + bytes | VarInt size + bytes |
| Block entities | VarInt count + NBT compounds | packed xz, short Y, VarInt type, NBT |
| Light | per-section 2048+2048 bytes inside section | trailing bitsets + light arrays (also Update Light packet) |
| Biomes | 1024 ints after sections if full chunk | paletted 64 entries per section |

## Sections / world height

- **393**: sections Y 0–15 (world Y 0–255). Bitmask selects present sections.
- **765**: default overworld sections −4…19 (24 sections). Negative Y / Y>255 exist.

**Conduit policy:** when translating 765 → 393, keep only sectionY in `[0,15]`. Sections outside that range are **dropped** (documented), not remapped into corrupt coordinates.

## Palette encoding

| | 393 | 765 |
|---|---|---|
| Storage | tight bit packing across longs | padded: `valuesPerLong = 64 / bits` |
| Indirect | bits 4–8 + palette VarInts | bits 0 single-value; blocks ≤8; biomes ≤3 |
| Direct / global | bits ≥9 (≈14 for 1.13 registry) | blocks ~15; biomes ~6 |
| Block count | derived | short non-air count before palette |

## Block states

Numeric IDs are **not** stable across versions. Conduit maps via Prismarine `blocks.json` name + relative state offset (`scripts/gen-blockstates.py` → `blockstates_*_*.bin`). Unknown / version-unique blocks fall back to **stone** (state 1). Air stays 0.

## Biomes

- 393: 1024 × int (4×4×Y columns). Missing → fill **plains** (id 1).
- 765: paletted 4×4×4 per section. Not forwarded as raw IDs into 393; plains fill used after height projection.

## Heightmaps

765 heightmap NBT is skipped on decode toward 393 (1.13 has no equivalent in Chunk Data). Encode toward 765 writes an empty anonymous NBT compound.

## Lighting

- 393: light inside each section body.
- 765: light after chunk body; separate **Update Light** packets exist.
- Conduit: embeds full-bright defaults when light missing for 393; **drops** Update Light toward 393 (no standalone packet).

## Compression

Frame compression is handled by the proxy framing layer (backend Set Compression consumed). Chunk codecs operate on already-uncompressed packet bodies and validate VarInt sizes before allocating.
